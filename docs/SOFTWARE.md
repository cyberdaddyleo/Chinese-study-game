竹林语文大作战是一款把中文词语、成语、错别字和古诗练习融入熊猫队与老虎队对战的浏览器游戏。答对题目即可派兵攻击对方竹屋，也可以独自完成 12 关练习。适合家庭学习、同伴互动和课堂练习；它不是与某一教材版本完全同步的题库，也不代替正式学习评价。

## 功能概览

| 功能 | 软件提供的内容 |
| --- | --- |
| 双人同屏 | 两队在同一设备答题，支持触屏；两边相同题号采用同一题型、不同题目 |
| 人机对战 | 简单、普通、困难三档电脑对手；每局 2、3 或 5 分钟 |
| 单人闯关 | 每个题库 12 关，每关 10 题，按正确率与用时评星 |
| 题型练习 | 释义选择、词语填空、正确写法、找错字、成语接龙、拼词、诗句接龙、古诗填字、诗句出处；设备支持中文语音时可出现听音题 |
| 自定义题库 | 粘贴词语、释义、易错写法和古诗，保存到本地浏览器 |
| 错题复习 | 错题本与复仇关；同一内容连续答对 2 次可从错题本移出 |
| 学习报告 | 近 7 天学习数据、累计各题型正确率与错题情况 |
| 可选 AI | 生成题库、拍照出题、故事闯关、记忆卡、造句评分、对战大招及学习周报 |

以上为各题库独立计数，不代表跨题库去重后的总数。题目会根据当前题库和模式生成；某些题型需要题库有相应词语或古诗内容。

## 运行方式

- 一个 `index.html` 即可运行核心游戏；无前端框架、安装包、依赖安装或构建步骤。
- 用支持 Canvas、SVG、Web Audio 和本地存储的现代浏览器打开。触屏设备可点击作答，电脑可使用鼠标或快捷键。
- 可本地打开，也可部署到静态网站服务。中文朗读取决于浏览器与设备提供的语音。
- 核心游戏不依赖 AI。AI 功能需要网络、可用的 OpenAI 兼容接口和自己的 API Key；使用费用按所选服务商规则计算。
- 图片识别需另填支持图像输入的模型；故事版与 AI 大招要求当前题库至少有 4 个词语。

## 技术组成与文件

画面由 SVG / Canvas 绘制，音效由 Web Audio 合成，朗读使用 `speechSynthesis`。记录写入浏览器 `localStorage`，键名为 `bamboo-hanzi-battle-v1`。外部字体加载失败时自动使用系统字体。

## 数据与使用边界

学习记录不会自动跨设备同步。清除站点数据、更换浏览器或改用另一访问地址时，原记录不会自动带过去；存储被禁用时记录仅保留在内存。

AI 调用会把相应内容和认证信息发送到用户配置的接口；使用 Worker 时还会经过中转服务。项目源码不包含可直接使用的 API Key。AI 输出可能有误，尤其是教材对应关系、古诗原文和解释，使用前应对照课本核对。

更多操作见 [使用指南](USER_GUIDE.md)，完整数据说明见 [README](../README.md#隐私与数据保存)。
